VolleyTwin 平板離線版

上傳方式
將 index.html、sw.js、manifest.webmanifest、icon-192.png、icon-512.png 五個檔案一起上傳到 volley-twin 儲存庫根目錄，替換同名檔。不要只上傳 HTML。

平板使用
1. 部署完成後，先連網開啟 https://x30s2664-design.github.io/volley-twin/
2. 等待「離線已準備好」。
3. iPad 使用 Safari 的分享選單，選「加入主畫面」；Android 使用瀏覽器的安裝或加入主畫面選項。
4. 從主畫面圖示連網開啟一次，再次確認「離線已準備好」。
5. 開啟飛航模式，關閉並重新開啟主畫面圖示，確認可操作。

所有人物、排球、姿勢、繪圖及雙視圖功能在離線模式可運作。JSON 建議定期匯出備份。瀏覽器清除網站資料或系統移除快取後，需重新連網準備。

更新程式時修改 sw.js 的 VERSION 字串。已通過模擬離線快取測試，尚未實體 iPad／Android 驗證。
